# Security Policy
<!-- page 1 -->
Acme Information Security Policy, owned by the Security team. Passwords. Account passwords must rotate every 90 days and must be at least 14 characters long. Password reuse across the last 12 passwords is blocked. Use the company password manager for all shared credentials; never store secrets in source code, chat, or tickets. Remote access. MFA is required for VPN access and for every administrative console. Hardware security keys are preferred over SMS codes.
<!-- page 2 -->
Incident reporting. Report suspected security incidents to security@acme.example within 1 hour of discovery, including phishing emails, lost laptops, and leaked credentials. Do not attempt to investigate a compromised machine yourself; disconnect it from the network and wait for the on-call security engineer. Laptops must use full-disk encryption and lock automatically after 5 minutes of inactivity.
